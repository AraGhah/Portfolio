# Hall of Projects — Ara Ghahramanyan

Portfolio Next.js rebuilt from the build specification in the parent `README.md`.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion 11 (available; door leaves use CSS transitions per spec)
- next-intl (`en` / `fr`)

## Commands

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run start
```

## Locales

- `/` — English (default)
- `/fr` — French (Quebec, professional register)

## Notes

- Door faces are pure CSS
- Case studies open as an overlay with swinging leaves; also available at `/projects/[slug]`
